# Monica for Windows (已停止维护)

> **⚠️ 项目状态：已归档**  
> 由于 Monica for Windows 的功能与浏览器插件版本高度重合，我们决定将开发重心转移到更具跨平台优势的 **浏览器扩展** 上。  
> 本仓库仅用于存档历史代码，不再接受新的功能开发或维护。

---

## 📦 关于 Monica for Windows

Monica for Windows 是基于 **WinUI 3** 和 **.NET 8** 开发的原生 Windows 密码管理器，曾提供：

- 🔐 本地加密的密码保险箱
- 🔄 WebDAV 跨设备同步
- 🛡️ AES-256-GCM 加密
- 🎨 Fluent Design 界面

## 🚀 迁移建议

如果您正在使用 Monica for Windows，我们建议您迁移到以下平台：

### 推荐方案 1：浏览器插件 (Chrome / Edge)
- **优势**：跨平台、自动填充、更新频繁
- **仓库**：[Monica for Browser](https://github.com/JoyinJoester/Monica/tree/main/Monica%20for%20Browser)
- **安装**：开发者模式加载或等待 Chrome Web Store 上架

### 推荐方案 2：Android 应用
- **优势**：移动端原生体验、Material Design 3
- **下载**：[GitHub Releases](https://github.com/JoyinJoester/Monica/releases)
